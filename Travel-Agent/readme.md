**目的**：
搭建一个能够处理分布任务的旅游助手

**例如**：

用户：帮我查询北京的天气，根据天气帮我选择一个合适的景点和出行工具

Agent：调用查询天气的工具，查询出结果进行观察，作为下一步的执行依据，然后循环此过程继续去调用景点推荐工具最终返回`final_answer`

用户发送任务去调用`llm`的核心是发送提示词工程`prompt engineer`，其实就是提示词。

所以我们需要设定一个“指令模板”，就是系统提示词，告诉`llm`它扮演着什么角色、拥有什么工具、如何格式化它的思考和行为，这也是我们所说的`Agenrt`的说明书

我们将会以系统提示词`system_prompt`的形式传给`llm`

**我们将会使用两个工具，就是调用两个API**
1. get_weather:查询真实的天气信息
2. search_attraction:根据当前城市的天气状况来搜索出合适的景点
-----

**总结**

旅行助手智能体
1. 系统提示词
2. 根据需求调用API工具，导入库，定义函数
3. 调用llm大模型
